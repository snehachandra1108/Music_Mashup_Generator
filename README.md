# Mixify — Per-track segment duration

## Run locally
1. Extract all files directly into your project folder.
2. Open `index.html` with VS Code Live Server.
3. Search Audius and add at least two tracks to the lineup.

## Set each song's duration
Each selected song has its own **Segment duration** slider (5–180 seconds, in 5-second steps). The default is 60 seconds. Adjust each song independently before generating the mashup. The estimated total duration updates as you change the sliders.

If a song is shorter than its selected segment duration, the mashup uses the full available song.

## Notes
- Music search and streaming use the Audius API.
- Exporting or remixing a track requires the relevant rights or permission. Stream availability does not itself grant remix or redistribution rights.
